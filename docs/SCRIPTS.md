זהו סקריפט חד-פעמי במהותו. הוא מלא בהדפסות ובניסוי וטעייה כי זו הייתה מטרתו:

הפונקציות המרכזיות שבהן השתמש:

| פקודה | מה מחזירה |

| `df.isnull().sum()` | כמה ערכים חסרים בכל עמודה |
| `df.head()` / `df.tail()` | השורות הראשונות והאחרונות — כאן התגלו שורות הזבל |

| שדה | ערך |
|---|---|
| תפקיד | להפוך את הקובץ הגולמי לקובץ נקי, באופן שחזיר |
| קלט | `data/telco_churn.xlsx` |
| פלט | `data/telco_churn_clean.csv` |
| הרצה | `python scripts/02_clean_data.py` |

בנוי משלושה חלקים מסומנים: `Clean`, `Verify`, `Save`.

### הטעינה

```python
df = pd.read_excel(RAW_PATH)
```

`df` הוא **DataFrame** — טבלה בזיכרון, המבנה המרכזי של pandas. אפשר לחשוב עליו
כגיליון Excel שחי בתוך פייתון: יש לו עמודות בעלות שם, שורות ממוספרות, וטיפוס
לכל עמודה.

### הניקוי — ארבע פעולות

```python
df = df[df["Churn"].isin(["Yes", "No"])].copy()
```

זו השורה החשובה בסקריפט. פירוק מבפנים החוצה:

| חלק | מה עושה |
|---|---|
| `df["Churn"]` | בוחר את העמודה |
| `.isin(["Yes", "No"])` | מחזיר עמודת אמת/שקר — `True` לכל שורה שערכה כן או לא |
| `df[ ... ]` | שומר רק את השורות שקיבלו `True` |
| `.copy()` | יוצר עותק עצמאי. בלעדיו pandas מתריע שאולי אתה משנה חתך של המקורי |

**זו הרשימה הלבנה:** מגדירים מה תקין, לא מה פגום. ראה `EXPLANATIONS.md` שלב 2.2.

```python
df["TotalCharges"] = df["TotalCharges"].fillna(0)
```

`fillna` ממלא ערכים חסרים. כאן באפס, כי כל החסרים שייכים ללקוחות בוותק אפס.

```python
df["SeniorCitizen"] = df["SeniorCitizen"].astype("int8")
```

`astype` ממיר טיפוס. `int8` הוא מספר שלם קטן — מספיק לעמודה שמכילה רק 0 ו-1.

```python
text_cols = df.columns[df.dtypes == "object"]
df[text_cols] = df[text_cols].astype("str").apply(lambda s: s.str.strip())
```

| שורה | מה עושה |
|---|---|
| `df.dtypes == "object"` | עמודת אמת/שקר: אילו עמודות הן מטיפוס כללי |
| `df.columns[...]` | הופך את זה לרשימת שמות העמודות |
| `.astype("str")` | מחזיר אותן לטיפוס טקסט מפורש |
| `.apply(lambda s: s.str.strip())` | מפעיל על כל עמודה קיצוץ רווחים מההתחלה והסוף |

`lambda` היא פונקציה קצרה בלי שם. `lambda s: s.str.strip()` פירושו "קבל עמודה,
החזר אותה בלי רווחים מיותרים".

בלוק ה-`Verify` לא מתקן כלום — רק מדפיס. מטרתו לענות על "איך אני יודע שהניקוי

## `03_load_to_sql.py` — טעינה למסד הנתונים

| שדה | ערך |
|---|---|
| תפקיד | ליצור את הטבלה במסד ולמלא אותה בדאטה הנקי |
| קלט | `data/telco_churn_clean.csv` + `sql/01_create_tables.sql` |
| פלט | טבלה `customers` במסד `telco_churn` |
| הרצה | `python scripts/03_load_to_sql.py` |

### הספריות

| ספרייה | תפקיד |
|---|---|
| `pandas` | קורא את ה-CSV ושולח אותו למסד |
| `sqlalchemy` | שכבת החיבור. pandas יודע לכתוב לטבלה רק דרכה |
| `psycopg2` | הדרייבר שמדבר בפועל עם PostgreSQL. לא מיובא ישירות — SQLAlchemy קורא לו |
| `dotenv` | קורא את `.env` כדי שהסיסמה לא תהיה בקוד |
| `subprocess` | מריץ פקודת מערכת. משמש לאיתור כתובת Windows |
| `decimal` | חשבון עשרוני מדויק, לבדיקת האימות |

### מילון השמות

```python
COLUMN_MAP = {
    "customerID": "customer_id",
    ...
}
```

מילון (`dict`) הוא זוגות של מפתח וערך. כאן: שם בקובץ ← שם במסד.

**למה 21 שורות ולא ביטוי אחד חכם:** הכלל הטבעי הוא "הוסף `_` לפני כל אות גדולה",
אבל הוא הופך את `customerID` ל-`customer_i_d` ואת `StreamingTV` ל-`streaming_t_v`,
כי `ID` ו-`TV` הן שתי אותיות גדולות רצופות. קוד מפורש שעובד עדיף על קוד דחוס
שנשבר על מקרה קצה.

### איתור כתובת Windows

```python
def windows_host_ip():
    route = subprocess.run(
        ["ip", "route", "show", "default"], capture_output=True, text=True, check=True
    )
    return route.stdout.split()[2]
```

המסד רץ ב-Windows והקוד רץ ב-WSL, שמגיע אליו דרך שער ברירת המחדל של הרשת.
הפקודה `ip route show default` מחזירה שורה כמו:

```
default via 172.31.48.1 dev eth0 ...
```

`.split()` מפרק לפי רווחים ו-`[2]` לוקח את האיבר השלישי — הכתובת.

**למה לא לכתוב את הכתובת ב-`.env`:** WSL מקבל כתובת חדשה בכל אתחול של המחשב.
כתובת קבועה בקובץ הייתה עובדת היום ונשברת מחר.

### החיבור

```python
load_dotenv()
host = os.environ["DB_HOST"]
if host == "auto":
    host = windows_host_ip()
```

`load_dotenv()` טוען את `.env` לתוך משתני הסביבה, ו-`os.environ["..."]` קורא
מהם. הערך `auto` הוא מתג: אם המסד היה מקומי היה כתוב שם `localhost`.

```python
engine = create_engine(
    f"postgresql+psycopg2://user:password@host:port/dbname"
)
```

זו **כתובת חיבור** בתקן אחיד, וזה אותו מבנה בכל מסד נתונים:

```
postgresql+psycopg2 :// postgres : ****** @ 172.31.48.1 : 5433 / telco_churn
‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾    ‾‾‾‾‾‾‾‾   ‾‾‾‾‾‾   ‾‾‾‾‾‾‾‾‾‾‾‾   ‾‾‾‾   ‾‾‾‾‾‾‾‾‾‾‾
   סוג מסד + דרייבר    משתמש     סיסמה       כתובת       פורט     שם המסד
```

`create_engine` **לא מתחבר** בשלב הזה. הוא בונה אובייקט שיודע איך להתחבר,
והחיבור עצמו נפתח רק בשימוש הראשון.

### יצירת הטבלה

```python
with engine.begin() as conn:
    conn.execute(text(open(DDL_PATH).read()))
```

| חלק | מה עושה |
|---|---|
| `open(DDL_PATH).read()` | קורא את קובץ ה-SQL כמחרוזת |
| `text(...)` | עוטף מחרוזת גולמית כפקודת SQL ש-SQLAlchemy מוכן להריץ |
| `engine.begin()` | פותח **טרנזקציה** — הכל מתבצע יחד או בכלל לא |
| `with ... as conn` | סוגר את החיבור אוטומטית בסוף, גם אם הייתה שגיאה |

**`begin()` מול `connect()`:** הראשון פותח טרנזקציה ומאשר אותה ביציאה, ומשמש
לכתיבה. השני משמש לקריאה בלבד.

הרצת קובץ ה-DDL מתוך הסקריפט שומרת על פקודה אחת לכל הצינור, וכיוון שהקובץ
מתחיל ב-`DROP TABLE IF EXISTS`, אפשר להריץ את הסקריפט שוב ושוב.

### הטעינה

```python
df = pd.read_csv(CLEAN_PATH).rename(columns=COLUMN_MAP)
df.to_sql(TABLE, engine, if_exists="append", index=False)
```

| פרמטר | משמעות |
|---|---|
| `.rename(columns=COLUMN_MAP)` | מחיל את המילון — 21 העמודות מקבלות את שמן במסד |

| `index=False` | בלי עמודת מספור מיותרת |

### בלוק האימות

הטעינה לא הסתיימה כשהסקריפט לא נפל — היא הסתיימה כשהוכחנו שהטבלה תואמת למקור.
שלוש בדיקות:

| בדיקה | מה מוכיחה |
|---|---|
| מספר שורות ב-CSV מול המסד | שום שורה לא נפלה בדרך |
| מספר מזהים ייחודיים = מספר שורות | אין כפילויות |
| סכום החיוב המצטבר ב-CSV מול המסד | שום ספרה לא השתנתה בהמרת הטיפוס |

הבדיקה השלישית היא החזקה מבין השלוש: היא בודקת את **תוכן** הדאטה ולא רק את כמותו.
שורה חסרה תיתפס גם בבדיקה הראשונה, אבל ערך שהשתנה תיתפס רק כאן.

```python
churn_rate = conn.execute(text(
    "SELECT round(avg(CASE WHEN churn = 'Yes' THEN 1 ELSE 0 END) * 100, 2) FROM customers"
)).scalar()
```

זו השאילתה שסוגרת החלטה משלב 2.2: **לא לאחסן עמודת נטישה מספרית, לגזור אותה.**
`CASE WHEN` מתרגם טקסט למספר בזמן אמת, `avg` נותן את הממוצע, וכפל ב-100 הופך
לאחוזים. אין עמודה נוספת בטבלה, ואין שתי גרסאות של אותה עובדה.

`.scalar()` מחזיר ערך בודד במקום טבלת תוצאה.
